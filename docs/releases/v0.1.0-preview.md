# WildScene v0.1.0-preview

首个供其他用户在本机部署的预发布版本。请下载附件 **WildScene-v0.1.0-preview.zip**，解压后阅读 `QUICKSTART.md`。

## 安装

- 需要 Node.js 24 LTS、桌面版 Edge / Chrome，以及自己的视觉模型 API Key。
- Windows：先运行 `install.cmd`，安装完成后运行 `start.cmd`，浏览器打开 `http://127.0.0.1:5173`。
- 部署包包含预构建网页；首次安装仍需联网下载运行依赖。
- 在“模型设置”填写 API 配置，并下载/导入官方 eBird v2026 CSV。发布包不含个人 Key、配置、分类表或照片。
- GitHub 自动生成的 Source code 包需构建；`node scripts/install.mjs` 会自动识别并处理。

## 功能

- 批量导入图片文件夹；文件列表、搜索、竖图适配和标签预览。
- OpenAI 兼容视觉 API，支持配置主模型、复核模型与并发。
- 本地 eBird v2026 英文名校验；疑难图片裁剪、按需阴影提亮及一次复核。
- 拍摄日期与经纬度作为批次上下文；支持 TXT/CSV 参考名单。
- 标签实时保存到照片目录 `tags.json`；重识别勾选保存在浏览器缓存。
- 开始/暂停、取消文件选择、日间/夜间模式及 API 用量统计。

## 验证与限制

- 67 项自动测试及 TypeScript/Vite 生产构建通过；部署附件在 Windows x64 的干净目录完成依赖安装、Sharp 原生加载、无个人配置启动与 HTTP 检查。测试不产生收费模型调用。
- 需要 Node.js；本附件未捆绑运行时。macOS/Linux 尚未完成平台实测。
- 仅支持本机部署，暂不提供多人远程服务与图片印字导出。
- 识别结果可能错误；待确认会保留最近候选，重要标签需人工核对。
- 迁移/升级配置时，请自行保护 `data/` 和 `.env`，不要将它们分享或提交到 Git。
